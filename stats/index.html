还没有历史快照。跑一次 python tools/site_stats.py 生成本地快照， 之后每次运行都会追加一行，趋势线才会出现。

数据源：GitHub Releases 的 download_count，每 6 小时由 GitHub 统计一次，含重复下载与镜像抓取，不等于独立用户数。
浏览器直接调 api.github.com，未登录时每 IP 每小时 60 次配额，额度用完等整点重置即可。
这个页面不放到导航里，也带 noindex；数据本身只有版本号与次数，不含任何访问者信息。
